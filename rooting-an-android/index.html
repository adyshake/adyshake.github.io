Rooting an Android Phone

2019-12-24

Download prerequisites

  • Magisk Manager
  • Magisk
  • TWRP Recovery
  • TWRP Recovery OP6
  • EdXposed Manager

Installation

First, copy over all the downloaded files on to the phone. Next, hold the Volume Down and Power button till phone vibrates. Then reboot into fastboot by navigating through the following menus, English -> Advanced -> Reboot to Fasboot

Once in fastboot, run the following command to boot into TWRP

fastboot boot ./twrp-3.3.1-2-enchilada.img

Now run the following steps,

  • Install the TWRP Recovery zip
  • Install Magisk
  • Reboot, and install the Magisk Manager and the EdXposed Installer APK
  • Open Magisk Manager, and download Riru - Core and Riru - EdXposed (SandHook)
  • Reboot

Some caveats

Deleting magisk modules doesn't work sometimes, so you can delete them manually by navigating to /data/adb/modules
