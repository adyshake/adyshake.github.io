It's been a while since the last update back in 2021. A lot has changed since. I moved to the Bay Area, got married, moved in with my wife and LLMs exist now!

It's a strange time to be a software engineer when it's so cheap to produce code. Sure, you have a much larger output, but there was a certain joy I used to feel when crafting code by hand and solving problems along the way. That has all but disappeared now. I recently tried writing code in Go manually and boy, it sure was difficult to do basic college-level exercises again. It's quite odd when you've had many many work hours of reading and reviewing the same language at work, but when asked to write by hand, from memory, it becomes a struggle to express your thoughts into a vocabulary that you distinctly lack. It's beginning to change the way I think about writing, learning and understanding. 

Not too long ago, I would use spell checkers, Grammarly and other tools to spot check my writing while I was doing it. I'm slowly trying to unlearn these bad habits to force my brain to actually learn how to do things the old way again. Whether it be plain old writing or programming. It is an interesting time to be alive in an era when knowledge work and creativity are being disrupted.
